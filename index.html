How it’s calculatedTry this yourself

Each line is the national pooled Standardized Infection Ratio (SIR): every infection hospitals reported, divided by every infection CDC’s risk models predicted for those same hospitals. Below 1.0 means fewer infections than predicted.

  1. 1
    Source

    CMS Care Compare HAI file, loaded into semantic model CMS, table HAI.

  2. 2
    Query

    One DAX query sums observed and predicted cases per infection, by REPORTYEAR.

  3. 3
    Calculate

    Pooled SIR = Σ observed ÷ Σ predicted. No weighting, filtering or smoothing.

  4. 4
    Draw

    One point per report year. Rounded to 2 decimals only when displayed.

Why pooled, not an average of hospitals

CMS only publishes a hospital’s SIR when at least one infection is predicted, so many hospitals have no published SIR but are still in the totals. Pooling counts every infection once, which is how NHSN aggregates SIRs for groups of hospitals.

You don’t have to trust this dashboard, the semantic model, or this panel. Here are four independent checks, quickest first.

1
Recalculate by hand
≈ 1 minute
  • 2025: 10,805 ÷ 17,570.315 = 0.614958 → 0.61, the big number in the panel.
  • Change: 0.614958 ÷ 0.684675 − 1 = −10.2% → −10%, the label under it.
2
Re-run the query in Fabric
≈ 5 minutes
  1. In the Fabric portal, open workspace contoso-quality and semantic model CMS.
  2. Choose Write DAX queries, paste the query below and select Run.
  3. Observed, predicted and hospital counts should match exactly.
DAX · validation query for CLABSICopy
EVALUATE
SUMMARIZECOLUMNS (
    HAI[REPORTYEAR],
    "Observed", SUM ( HAI[HAI_1_NUMERATOR-…: Observed Cases] ),
    "Predicted", SUM ( HAI[HAI_1_ELIGCASES-…: Predicted Cases] ),
    "Pooled SIR", DIVIDE ( SUM ( HAI[…Observed Cases] ), SUM ( HAI[…Predicted Cases] ) )
)
ORDER BY HAI[REPORTYEAR]
3
Trace it back to CMS’s own files
≈ 15 minutes
  1. Download the report year’s snapshot from the CMS hospitals data archive.
  2. Open Healthcare_Associated_Infections-Hospital.csv in Excel.
  3. Observed: =SUMIFS(L:L, I:I, "HAI_1_NUMERATOR")
  4. Predicted: =SUMIFS(L:L, I:I, "HAI_1_ELIGCASES"), then divide.

An automated check repeats this for every infection and year: all 42 infection-years match exactly.

4
Sanity-check against CDC
optional

CDC’s HAI Progress Report publishes national SIRs from the same NHSN system. Expect the same direction and similar size, not identical values.
